# Метрики успадкованого модуля

## До рефакторингу

Спосіб вимірювання: вручну. LOC — рядки без порожніх і без рядків лише з коментарем
(сигнатура й фігурні дужки враховуються). CC = 1 + кількість точок розгалуження
(if, else if, case, for, foreach, while, catch, &&, ||, ??, тернарний оператор).

| Метод | LOC | CC | Глибина вкладеності | Параметрів |
|-------|-----|----|---------------------|------------|
| Handle | 80 | 17 | 4 | 11 |
| Preview | 28 | 9 | 2 | 3 |
| DescribeClient | 10 | 3 | 1 | 1 |
| DumpLog | 6 | 2 | 1 | 0 |
| Клас LegacyTicketProcessor загалом | 130 | — | — | — |
| Файл LegacyTicketProcessor.cs загалом | 149 | — | — | — |

### Розрахунок CC методу Handle

| Точка розгалуження | Рядок | Кількість |
|--------------------|-------|-----------|
| if (lines != null) | 36 | 1 |
| if (lines.Count > 0) | 38 | 1 |
| if (state == "new" \|\| state == "paid") — if та \|\| | 40 | 2 |
| if (clientMail != null && ...) — if та && | 42 | 2 |
| два цикли for | 68, 96 | 2 |
| три перевірки виду клієнта (if / else if / else if) | 74, 79, 84 | 3 |
| три перевірки межі знижки > 500m | 77, 82, 87 | 3 |
| if (_tmpSum - _tmpDiscount < 1000m) | 91 | 1 |
| if (sendMail) | 109 | 1 |
| **Разом точок розгалуження** | | **16** |

CC(Handle) = 1 + 16 = 17.

### Додатково

- Відповідальностей класу — 7: перевірка вхідних даних, арифметика суми, знижки,
  доставка, форматування звіту, журналювання, опис клієнта.
- Дубльованих рядків між Handle і Preview — 14 (сума, знижка, доставка).
- Магічних чисел — 7: 0.15m, 0.30m, 0.05m, 500m, 1000m, 60m, 10.
- Невикористаних параметрів Handle — 2: clientId, createdAt.
